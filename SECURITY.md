# Security

Keep Agent Fort on loopback and use a private HTTPS transport such as Tailscale Serve. The app can launch Hermes tasks and expose stored conversation history to authenticated clients. Treat the access key like a password and keep your tailnet membership restricted to intended users.

Please report security issues privately through GitHub's private vulnerability reporting if enabled, or contact the maintainer through their GitHub profile before sharing exploit details publicly. Do not include API keys, cookies, access keys, or real private transcripts in an issue.
